# محرك التسعير والعروض التدريبية
# Training Proposal & Pricing Engine

نظام إدارة تجاري داخلي متكامل لمعهد تدريب سعودي

---

## نظرة عامة / Overview

محرك تسعير وعروض تدريبية متكامل يُغطي دورة الحياة الكاملة لإدارة التكاليف والتسعير التجاري لبرامج التدريب المؤسسي، المناقصات الحكومية، برامج التهيئة الوظيفية، الشهادات المهنية، والعقود التدريبية الكبيرة.

---

## الميزات المُنجزة / Completed Features

### إدارة المشاريع
- إنشاء / تعديل / حذف / نسخ / أرشفة المشاريع
- لوحة تحكم بجميع المشاريع مع الحالة التجارية
- حقول مشروع شاملة (رقم، عميل، نوع، عقد، مدينة، تواريخ، مشاركون، إلخ)

### الإعدادات العالمية للتكاليف
- إدارة جميع معدلات التكلفة الافتراضية
- 26 بنداً من بنود التكاليف (مدربون، موظفون، قاعات، مواد، سفر، تقنية، إلخ)
- دعم تجاوز الإعدادات على مستوى المشروع دون تغيير الإعدادات العامة

### بناء التكاليف
- حساب تلقائي لجميع التكاليف المباشرة (17 بنداً)
- حساب التكاليف غير المباشرة (إدارية + طوارئ)
- عرض نسبة كل بند من الإجمالي
- حسابات: تكلفة/متدرب، تكلفة/يوم، تكلفة/دفعة، تكلفة/برنامج

### محرك التسعير
- **ثلاثة سيناريوهات آلية:**
  - السيناريو أ: تنافسي (15% هامش افتراضي)
  - السيناريو ب: موصى به (25% هامش افتراضي) ⭐
  - السيناريو ج: مميز (35% هامش افتراضي)
- تعديل الهامش يدوياً لكل سيناريو
- حساب: سعر قبل الضريبة، ضريبة القيمة المضافة، سعر شامل الضريبة، ربح إجمالي، هامش، إيراد/متدرب

### تحليل التعادل
- حساب سعر التعادل (هامش صفر)
- الحد الأدنى المقبول للسعر
- هامش الأمان فوق التعادل
- تحذيرات عند السعر أقل من التعادل أو أقل من الحد الأدنى

### تحليل الحساسية
- أشرطة تمرير تفاعلية لـ 8 متغيرات
- تأثير فوري على: التكلفة، السعر، الربح، الهامش
- مقارنة القاعدة مقابل المعدّل

### جدول الكميات BOQ
- إضافة/تعديل/حذف/نسخ البنود
- توليد تلقائي من بناء التكاليف
- حساب: إجمالي قبل الضريبة، ضريبة، إجمالي شامل الضريبة

### جدول الدفعات
- إدارة المراحل والنسب
- توليد جدول افتراضي (30/30/25/15)
- التحقق من مجموع النسب = 100%
- تتبع الحالة (قيد انتظار/صدر فاتورة/مستلم/متأخر)

### التدفق النقدي
- مقارنة المدفوعات المستلمة vs التكاليف المتوقعة
- الوضع النقدي والتراكمي
- مخطط بصري

### لوحة الإدارة التنفيذية
- 8 بطاقات KPI مع مؤشرات اللون
- 4 رسوم بيانية: توزيع التكاليف، مقارنة السيناريوهات، أكبر عناصر التكلفة، الربحية

### توصية الإدارة
- توليد تلقائي للتوصية
- عناصر قابلة للتعديل: عوامل التكلفة، المخاطر، الملاحظات، القرار
- تحذير عند ضعف الهامش

### التقارير
- ملخص التسعير التنفيذي
- كشف التكاليف المفصّل
- BOQ للعميل
- مقارنة السيناريوهات
- جدول الدفعات
- تحليل الربحية
- توصية الإدارة
- قابل للطباعة

## الحسابات المالية / Financial Formulas

```
التكاليف المباشرة = مجموع كل بنود التكاليف المباشرة
الإدارية = التكاليف المباشرة × نسبة الإدارية%
الطوارئ = التكاليف المباشرة × نسبة الطوارئ%
إجمالي التكلفة = مباشرة + غير مباشرة

سعر البيع (قبل الضريبة) = إجمالي التكلفة ÷ (1 - الهامش%)
ضريبة القيمة المضافة = سعر البيع × نسبة الضريبة%
الربح الإجمالي = سعر البيع - إجمالي التكلفة
هامش الربح = (الربح الإجمالي ÷ سعر البيع) × 100
```

## دليل الاستخدام / User Guide

1. **افتح** التطبيق من الرابط أعلاه
2. **الداشبورد**: عرض عام لجميع المشاريع
3. **مشروع جديد**: اضغط "مشروع جديد" أو "تحميل مشروع تجريبي"
4. **بناء التكاليف**: أدخل/عدّل معدلات التكلفة
5. **محرك التسعير**: راجع السيناريوهات وعدّل الهوامش
6. **التحليلات**: راجع التعادل والحساسية
7. **BOQ**: اضغط "توليد تلقائي" أو أضف بنوداً
8. **جدول الدفعات**: اضغط "جدول افتراضي" أو أضف مراحل
9. **التقارير**: اطبع/شارك التقارير
